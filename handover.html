รหัสผ่านเข้าเว็บ: (ห้ามเขียนลงเอกสารที่เผยแพร่ ให้บอกปากเปล่า/ช่องทางส่วนตัว)

สรุปการทำงาน: กรอกข้อมูลในชีต → เปิดเว็บ → กดรีเฟรช → เว็บดึงข้อมูลล่าสุดมาแสดง · เว็บอ่านอย่างเดียว ไม่เขียนกลับลงชีต

2สิ่งที่ต้องทำทันทีเมื่อมีการโยกย้าย ⚠️

ข้อที่พลาดไม่ได้: Google Sheet ผูกอยู่กับบัญชี Google ส่วนตัวของผู้ดูแลคนเดิม ถ้าบัญชีนั้นถูกปิด/เลิกใช้โดยยังไม่โอนสิทธิ์ แดชบอร์ดจะดึงข้อมูลไม่ได้ทันที และข้อมูลย้อนหลังทั้งหมดอาจเข้าไม่ถึงอีกเลย ให้ทำข้อ 2.1 ก่อนวันสุดท้ายเสมอ

2.1 โอนสิทธิ์เจ้าของ Google Sheet

  1. เปิด Google Drive → คลิกขวาที่ไฟล์ชีต → แชร์
  2. เพิ่มอีเมลของผู้รับมอบ ตั้งเป็น ผู้แก้ไข → ส่ง
  3. กด ⋮ (จุดสามจุด) ข้างชื่อผู้รับมอบ → โอนความเป็นเจ้าของ → ยืนยัน
  4. ผู้รับมอบเปิดอีเมลแล้วกด ยอมรับ (ถ้าไม่กด การโอนจะไม่สมบูรณ์)
ห้ามลืม: หลังโอนแล้ว ตรงหัวข้อ "การเข้าถึงทั่วไป" ต้องยังเป็น "ทุกคนที่มีลิงก์ = ผู้อ่าน" เสมอ — ถ้าเผลอตั้งเป็น "จำกัด" เว็บจะดึงข้อมูลไม่ได้และตกไปแสดงข้อมูลตัวอย่างทันที

2.2 ส่งมอบสิทธิ์เว็บ (GitHub)

เว็บถูกเก็บและเผยแพร่ด้วยบัญชี GitHub ttharkesm-admin01 (repo ชื่อ -AI)

  • วิธีง่าย: เชิญผู้รับมอบเป็น Collaborator (Settings → Collaborators) — ลิงก์เว็บไม่เปลี่ยน แต่บัญชีเดิมยังเป็นเจ้าของอยู่
  • วิธีถาวร: โอน repo ไปบัญชีใหม่ (Settings → Transfer ownership) — ลิงก์เว็บจะเปลี่ยนตามชื่อบัญชีใหม่ ต้องแจ้งทุกคนที่บุ๊กมาร์กไว้

ถ้าไม่มีใครดูแลฝั่งเว็บได้ อย่างน้อยต้องมีคนเข้าบัญชี GitHub นี้ได้ ไม่งั้นแก้ไขเว็บ/เปลี่ยนรหัสผ่านไม่ได้เลย

2.3 รหัสผ่านเข้าเว็บ

  • บอกรหัสปัจจุบันให้ผู้รับมอบ แล้วเปลี่ยนรหัสใหม่หลังส่งมอบเสร็จ
  • การเปลี่ยนรหัสต้องแก้ไฟล์ในเว็บ (ดูข้อ 6) — ถ้าทำเองไม่ได้ ให้แจ้งผู้ดูแลฝั่งเว็บ
  • เปลี่ยนรหัสแล้ว ทุกคนจะหลุดจากระบบ ต้องแจ้งทีมล่วงหน้า

2.4 เช็กลิสต์ก่อนปิดงาน

  • ผู้รับมอบ เปิดชีตแล้วแก้ไขได้จริง (ลองพิมพ์อะไรสักอย่างแล้วลบออก)
  • ผู้รับมอบ เข้าเว็บด้วยรหัสผ่านได้จริง และเห็นข้อมูลเดือนล่าสุด
  • ผู้รับมอบ กดส่งออก PNG / Excel ได้
  • โอนสิทธิ์เจ้าของชีตเรียบร้อย และผู้รับมอบกดยอมรับแล้ว
  • ผู้รับมอบเข้าถึงบัญชี GitHub หรือมีคนที่เข้าได้
  • เปลี่ยนรหัสผ่านเว็บเป็นชุดใหม่
  • มอบคู่มือฉบับนี้ (พิมพ์หรือไฟล์ PDF) ให้ผู้รับมอบ

4วิธีใช้แดชบอร์ด

  1. เปิดเว็บ → ใส่รหัสผ่าน (ระบบจำไว้ 8 ชั่วโมง · ใช้เครื่องร่วมกับคนอื่นให้กด ออกจากระบบ ทุกครั้ง)
  2. เลือกแดชบอร์ด: OE ค่าใช้จ่าย หรือ สวัสดิการพนักงาน
  3. ดูแถบสถานะบนสุดให้เป็น 🟢 เชื่อม Google Sheets พร้อมช่วงเดือนที่โหลดมา (เช่น 171 รายการ • ม.ค.–ก.ค. 69)
  4. กรองด้วย ปี / เดือน / หมวดหมู่ / พนักงาน ตามต้องการ
  5. กดส่งออกตามงานที่ใช้:
ปุ่มได้อะไร / ใช้ตอนไหน
ส่งออก PNG / PDFรายงานสรุปหน้าเดียว A4 แนวนอน — ส่งให้ผู้บริหาร/แนบไลน์
Export PowerPointไฟล์ .pptx หลายสไลด์ — ใช้ในที่ประชุม
ส่งออก Excelไฟล์ .xlsx ข้อมูลดิบตามตัวกรอง — เอาไปคำนวณต่อ
จัดการข้อมูลแก้ข้อมูลชั่วคราวเฉพาะในเครื่องนี้ ไม่ได้เขียนกลับลงชีต — ใช้ลองดูตัวเลขเฉย ๆ ของจริงต้องแก้ในชีต
คนที่ไม่ต้องเข้าเว็บ (เช่น ผู้บริหาร หน่วยงานอื่น) ให้ส่งไฟล์ PNG/PDF/Excel ให้แทน ไม่ต้องบอกรหัสผ่าน

5ปัญหาที่เจอบ่อย & วิธีแก้

อาการสาเหตุที่พบบ่อยที่สุดวิธีแก้
กรอกข้อมูลเดือนใหม่ในชีตแล้ว แต่เว็บไม่ขึ้น แถบสถานะเขียนว่า "ข้อมูลตัวอย่าง (Demo)" = หน้านั้นยังไม่ได้ต่อชีต กด เชื่อม Google Sheets → วางลิงก์ชีต → แก้ชื่อแท็บให้ตรง (OE หรือ สวัสดิการ ไม่ใช่ค่าเริ่มต้น RAW_DATA)
เหมือนข้างบน แต่สถานะเป็นสีส้ม "แก้ไขในเครื่อง" เคยกดแก้ข้อมูลในเครื่องไว้ ข้อมูลถูกแช่แข็งทับชีตอยู่ กด จัดการข้อมูล → ล้างข้อมูลที่แก้ไข แล้วรีเฟรช
สถานะสีแดง "ต่อชีตไม่ได้" ไฟล์ไม่ใช่ Google Sheets แท้ (เป็น .xlsx ที่อัปโหลดไว้) หรือการแชร์ถูกตั้งเป็น "จำกัด" เปิดไฟล์ → ไฟล์ → บันทึกเป็น Google ชีต แล้วใช้ไฟล์ใหม่ · และตั้งแชร์เป็น ทุกคนที่มีลิงก์ = ผู้อ่าน
แก้เว็บแล้วแต่ยังเห็นของเก่า เบราว์เซอร์แคชไว้ กด Ctrl + Shift + R (Mac: Cmd + Shift + R) หรือรีเฟรช 2 ครั้ง
กราฟไม่ขึ้น / ส่งออกไม่ได้ อินเทอร์เน็ตมีปัญหา (กราฟและตัวส่งออกโหลดจากอินเทอร์เน็ต) เช็กเน็ตแล้วลองใหม่
ยอดคืนเงินยืมไม่ขึ้น สะกดประเภทไม่ตรง หรือใส่ยอดติดลบ ใช้คำว่า คืนเงินยืมทดรอง และใส่ยอดเป็นบวก
เข้าเว็บแล้วเด้งกลับหน้าใส่รหัสตลอด เบราว์เซอร์ปิดการเก็บข้อมูลเว็บไซต์ / เปิดโหมดส่วนตัว ปิดโหมดส่วนตัว หรืออนุญาตคุกกี้/ข้อมูลเว็บไซต์ แล้วลองใหม่

6งานที่ต้องใช้คนดูแลฝั่งเว็บ

งานเหล่านี้ต้องแก้ไฟล์ในโค้ดเว็บ (บัญชี GitHub) ไม่สามารถกดจากหน้าเว็บได้:

ต้องการทำอย่างไร
เปลี่ยนรหัสผ่านเข้าเว็บ เปิดเว็บ → กด F12 → แท็บ Console → พิมพ์ Auth.makeConfig('รหัสใหม่') → คัดลอกบล็อกที่ได้ (ไม่มีรหัสอยู่ในนั้น) ไปวางแทน CONFIG ในไฟล์ assets/auth.js แล้วเพิ่มเลข CACHE_VERSION ในไฟล์ sw.js
เพิ่ม/แก้หัวข้อในแดชบอร์ดแก้ไฟล์ oe/index.html หรือ welfare/index.html
ดูบันทึกทั้งหมดของโปรเจกต์ไฟล์ CLAUDE.md ใน repo — รวมกติกา ข้อควรระวัง และประวัติการแก้ทุกครั้ง
ห้ามเขียนรหัสผ่านตัวจริงลงไฟล์ในโค้ด — โค้ดเว็บนี้เปิดสาธารณะ ใครก็อ่านได้ ระบบจึงเก็บไว้เป็นรหัสที่เข้ารหัสแล้วเท่านั้น

7ข้อห้าม 5 ข้อ

  1. ห้ามตั้งการแชร์ชีตเป็น "จำกัด" — เว็บจะดึงข้อมูลไม่ได้ทันที (ต้องเป็น "ทุกคนที่มีลิงก์ = ผู้อ่าน")
  2. ห้ามสลับ/แทรก/ลบคอลัมน์ในชีต — ระบบอ่านตามตำแหน่งคอลัมน์ ไม่ได้อ่านจากชื่อหัวตาราง
  3. ห้ามใส่จำนวนเงินติดลบหรือ 0 — แถวนั้นจะหายไปจากทุกหน้าจอโดยไม่มีคำเตือน
  4. ห้ามเปลี่ยนชื่อแท็บ OE / สวัสดิการ โดยไม่ไปแก้การตั้งค่าในเว็บด้วย
  5. ห้ามเผยแพร่ลิงก์ชีตหรือรหัสผ่านให้คนนอก — ในชีตมีชื่อพนักงานคู่กับยอดค่ารักษาพยาบาล ซึ่งเป็นข้อมูลส่วนบุคคลที่อ่อนไหวตาม PDPA (คนนอกให้ส่งเป็นไฟล์ PNG/PDF แทน)
